# Screenshots

The main README banner is an **illustrative SVG diagram**, not a screenshot.

To produce an authentic screenshot:

1. Install with `python -m pip install -e ".[ui,dev]"`.
2. Start with `python -m streamlit run app.py`.
3. Upload `examples/sample.md`, build a skill and capture the actual browser window.
4. Save the image as `assets/streamlit-real.png` and add a README image link only after confirming that file is committed.
5. Redact any confidential or personal data.

The project's earlier marketing illustration is not an application screenshot, and the star count and quality percentages depicted in it are not verified.
