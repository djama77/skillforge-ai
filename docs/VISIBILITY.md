# Community launch checklist

SkillForge AI earns attention by being demonstrably useful. Stars are voluntary and never guaranteed.

## Public launch
1. Test installation on clean Windows, Linux and macOS environments.
2. Capture a real Streamlit screenshot after launching the app; do not depict illustrative mockups as evidence.
3. Record a short screen capture using a permitted public PDF, showing source upload, generated skill, provenance and quality report.
4. Share the demonstration on GitHub Discussions, relevant developer communities and technical forums, following their posting rules.
5. Publish a release only after testing PDF extraction, optional Ollama and packaging on real machines.
6. Label beginner-friendly issues, respond to bug reports and credit external contributors.

## Suggested keywords
ai-agent-skills, document-to-skill, ollama, local-ai, streamlit, python, agent-tools

## Short pitch
Turn PDF, Markdown and text documents into reviewable agent-skill drafts with source provenance, an optional local language model and structural checks.

## What not to claim
Do not claim 1.2k stars, 95% validated safety, 86% test coverage, published PyPI packages, universal native integrations, or verified factual accuracy without independent evidence.

## Growth metrics
Track unique contributors, recurring users, validated installations, issues resolved, downloads (once published), and GitHub stars as one of several indicators.
